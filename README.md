# 技能节点工作台

把短视频流水线的九个节点做成可替换的技能槽位：上传技能、绑定到节点、随时更换，不用改代码。

## 怎么打开

双击 `index.html` 即可，不需要 Node、不需要联网。也可以用 `打开工作台.bat`。

技能、绑定关系、参数都保存在这台电脑的浏览器里（localStorage），换浏览器不会带过去。

## 九个节点

| 序 | 节点 | 作用 |
| --- | --- | --- |
| 00 | 一句话创意 | 流程起点，只接创意与参数 |
| 01 | 创意分析 | 拆主题、受众、钩子、核心信息、视觉基调 |
| 02 | 剧本脚本 | 镜头级剧本，每场带旁白、字幕、画面 |
| 03 | 美术提示词 | 翻译成生图提示词，统一机位光线与负向词 |
| 04 | 美术资产 | 批量生图任务单，支持单张重试与落盘 |
| 05 | 拆解分镜 | 剧本与美术对齐成镜头表 |
| 06 | 每镜视频提示词 | 一镜一段可提交的视频提示词 |
| 07 | 视频任务包 | 打包成可交付、可复用的任务包 |
| 08 | 最终成片 | 成片验收清单 |

## 技能就是一份 Markdown

```markdown
---
id: script-four-beat
name: 剧本脚本 · 四拍结构
node: script
kind: text
version: 1.0
order: 1
tags: 剧本, 四拍
---

## 说明
给这个节点看的简介，会显示在技能卡片上。

## 系统提示词
给模型的身份与硬约束。

## 模板
创意分析：{{analysis}}
参数：{{sceneCount}} 镜，{{duration}} 秒，画幅 {{ratio}}。

输出 JSON：{...}
```

字段说明：

- `node` 决定挂在哪个节点，取值 `analysis`、`script`、`artPrompts`、`assets`、`storyboard`、`shotPrompts`、`pack`、`final`，写 `any` 表示任意节点可用。
- `kind` 只是分类标签，写 `text`、`image`、`video`、`pack`、`check` 都行。
- `order` 决定同一节点内多个技能的默认顺序，第一个生效。
- 占位符 `{{brief}}`、`{{style}}`、`{{ratio}}`、`{{duration}}`、`{{sceneCount}}` 来自顶部参数；`{{analysis}}`、`{{script}}` 等取自上游节点的产出，也可以写 `{{analysis.theme}}` 逐字段取。

`skills/格式示例-剧本四拍.md` 可以直接改成自己的技能再上传。

## 上传

技能库支持三种：

- `.md` 单文件：一个文件一个技能。
- `.zip` 技能包：包里的所有 `.md` 都会被尝试解析，带 `## 模板` 或 `## 系统提示词` 的才收；参考文件、图片会被忽略。
- `.json` 技能集合：本工作台「导出全部技能」生成的文件，用来整包搬家。

同名 `id` 已存在时会先问你要不要替换，不会静默覆盖。

## 换技能

- 画布上点节点 → 节点面板里能看到当前绑定的技能、顺序和装配后的提示词。
- 「添加到此节点」可以再挂一个技能，第一个生效，其余留作备选。
- 上移、下移、解绑随时可做，改完立刻生效。
- 技能库里「绑定到节点」「取消绑定」也能直接改。

## 两种运行方式

- **本地装配**（默认）：不配置任何地址时，「一键拆解」按技能模板把每个节点的提示词填好，上游产出用占位符接住。适合先确定流程和话术，不花调用费。
- **模型通道**：在「模型通道」里填 OpenAI 兼容的接口地址、模型名和 Key 后，「一键拆解」会按节点依次真实调用，上一节点的产出作为下一节点的输入。Key 只存本机浏览器，不写进任何文件。

「导出任务包」会把每个节点用的技能、提示词、产出打包成一份 JSON，可以直接拿到完整程序里执行，或者交给别的模型。

## 目录

```
技能节点工作台/
├─ index.html                  页面
├─ styles.css                  样式
├─ app.js                      节点编排、技能注册、上传解析、运行
├─ lib/skill-format.js         技能解析 / 序列化 / 模板渲染 / ZIP 读取
├─ skills/builtin.js           10 个内置技能
├─ skills/格式示例-剧本四拍.md   可上传的技能格式示例
├─ tests/test-skill-format.js  本机单元测试
└─ 打开工作台.bat
```

跑测试：

```bash
node tests/test-skill-format.js
```

## 现在的边界

- 只在本机跑，没有后台服务，不写数据库；数据随浏览器走。
- 美术生图、视频提交这两步在本工作台只产出提示词和任务单，不直接出图出片；真实生成交给完整程序里的通道。
- 模型通道的连通性取决于你填的地址，本工作台不内置任何账号。
